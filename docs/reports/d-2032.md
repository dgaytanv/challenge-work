It wins in **every** family, and clean AUC is 0.025 *above* the anchor, so this is not a
robustness-for-accuracy trade; standing ruling 3 is satisfied with room to spare.

**What this measures.** Training used `use_degradation: false` — the encoder never saw a dead
region. So +0.030 mean_area over the stock transformer *with* the mask fix is the intrinsic
robustness of symmetric pooling: a dead region removes terms from a masked mean/max over survivors
instead of corrupting a single CLS token that every dead candidate still fed into. Augmentation
(WP-B) and two-view consistency (WP-C) should stack on top of this, not compete with it.

**Caveat, stated plainly.** The rect curve is not monotone across severity —
AUC = 0.885, 0.863, 0.830, 0.711, 0.572, 0.600 at s = 0, 0.2, ... 1.0. The high-severity tail is
noisy, so I would put roughly +/-0.005 of run-to-run noise on these areas. A `--full` re-bench is
needed before any final architecture ruling.
