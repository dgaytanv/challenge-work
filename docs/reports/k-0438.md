## Recommendation, stated against the rule
**No WP-K arm is promotable.** None reaches the reference seed mean 0.826314, so none is eligible
under either route: not separably above (needs ≈0.8335), not within the non-separable route
(needs ≥0.828314). K1 is the only arm whose difference from the reference is too small to call at
all; the other two are genuine regressions. **The champion should go to submission unchanged as
far as this package is concerned.**

## What the package established, none of it a promotion case
- **The offset penalty controls the offset.** Within the two-view arm, λ 0 → 0.01 takes the
  offset from 14.191 to 0.078 while the spread rises 0.221 → 0.289. Both terms reported.
- **Scale-invariant improvements are real** (WP-I, same instrument, 4000 clean eval events):
  cond 78.2 → 32.4, effective rank 1.68 → 1.94. A uniform rescale cannot produce either.
- **Attribution is unresolved.** Champion → K1 also shrinks the latent ~32×, and WP-D measured
  the two-view consistency term alone compressing 5.7×, so the shrink is most plausibly the MSE
  term rather than the penalty. The settling row (two-view + MSE at λ=0, full small file) was not
  run under the 05:25 stop.
- **K5 is a null with an identified degenerate minimiser.** `diff·cov⁻¹·diff` is satisfied by
  inflating variance along the drift direction; the latent collapses to effective rank 1.00
  (cond 37,820, val AUC pinned at 0.73). Caught only because WP-I made me add effective rank.
- **K2 is a result about what the probe needs.** Normalising the latent onto the unit sphere
  costs 0.0264 of mean_area — separably worse. Its pre-normalisation offset ratio is 22×, so the
  arm does not remove the pathology, it hides it from the probe; and doing so hurts. The probe
  uses latent magnitude, not only direction.
