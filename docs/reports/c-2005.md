## What changed
- `src/embedding/degradation.py` — placeholder rectangle degradation, exact text from `wp-a.md`
  (train: p=0.2 clean, else K~{1,2,3} rects, d_eta~U(0.5,2.5), d_phi~U(0.3,1.2), phi wraps;
  eval: one rect of area s×plane). Vectorised, no per-event Python loop.
- `src/embedding/training.py` — `train_epoch`/`validate_epoch` take `two_view` and build
  `x2 = cat([x_clean, x_degraded])` on the batch dim, duplicate mask+labels, do ONE forward
  through preproc (so BatchNorm sees both views) and the encoder, then split `z_c, z_d`.
- Consistency acts on the **latent** (pre-projector), which is what the grader's probe sees:
  `consistency_weight * mean(1 - cos(z_d, z_c.detach())) + consistency_mse_weight * mse(z_d, z_c.detach())`.
  Stop-grad on the clean branch, so the degraded view is pulled toward the clean one.
- `src/embedding/loss.py` — added `NTXentInstanceLoss` (SimCLR; the only positive of view i is its
  counterpart view), wired as `instance_weight`, default 0.0.
- `train.py` + `configs/train_config.yaml` — keys `two_view`, `consistency_weight`,
  `consistency_mse_weight`, `instance_weight`, `seed`. Per-epoch logging of every loss term,
  `cos(z_c,z_d)` on train and val, and classifier accuracy on the degraded view.
- Checkpoint format unchanged. `eval.py` untouched.
