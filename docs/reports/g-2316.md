## API notes (read from installed source, not guessed)
- `hgq.config.LayerConfigScope(beta0=..., enable_ebops=...)` and `hgq.config.QuantizerConfigScope(...)` are the
  context managers for defaults; `hgq/config/layer.py` `global_config = {beta0: 1e-5, enable_ebops: True,
  enable_oq: False, enable_iq: True, enable_sq: True}`.
- The resource regulariser is per-layer: `hgq/layers/core/base.py` `QLayerMeta.__call__` wraps `call` and does
  `self._ebops.assign(...); self.add_loss(ebops * self.beta)`. **EBOPs are only accumulated when `training` is
  truthy or `'tracing'`** — an inference-mode forward reports nothing. `beta0` is the sweep knob for G2.
- `hgq.utils.trace_minmax(model, data)` calibrates the integer bits of WRAP-overflow datalane quantizers; needed
  because `kif_datalane_default` uses `overflow_mode='WRAP'`. Sugar callbacks: `FreeEBOPs`, `BetaScheduler`,
  `ParetoFront`, `EarlyStoppingWithEbopsThres` (`hgq/utils/sugar/`).
- `QSoftmax(axis=..., stable=True)` has `call(inputs, training=None, mask=None)` and applies
  `mask*inputs - (1-mask)*1e9` before the exp table, then re-masks `exp_inp`. **The masked softmax the encoder
  needs is natively supported** — this was the main risk in the prompt and it is retired.
- `QMultiHeadAttention` takes `attention_mask` / `query_mask` / `value_mask` and routes them to `_masked_softmax`.

## The one blocking architectural finding
`grep -rn "LayerNorm\|layer_norm"` over the whole `hgq` package returns **zero hits**. HGQ2 has
`QBatchNormalization`, `QBatchNormDense`, `QEinsumDenseBatchnorm` — but **no quantized LayerNorm**.
The certified encoder uses LayerNorm in four places (2x in `_phi_mlp`, `norm_pooled` on the 512-d flattened
pooled vector). Consequence: the "hardware-friendlier variant" in G2 (LayerNorm -> BatchNorm) is **not an
optional extra row, it is the only fully-quantizable path**. I will still build the LayerNorm version in G1/G2
with LayerNorm left in float on the host, and report both, so the cost of the swap is measured rather than assumed.
GELU is fine: `QUnaryFunctionLUT` implements arbitrary unary functions as LUTs.
